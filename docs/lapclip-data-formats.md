# LapClip `result.php` データ書式メモ

パーサ（[`src/userscript/parseDom.ts`](../src/userscript/parseDom.ts)）が依存する、LapClip リザルトページの DOM 構造とレース種別ごとの書式メモです。**レース当日のパーサー校正**の基準として使います。

> ここに載せるのは「書式の構造」だけです。実際のリザルト（選手名・タイム）は保存・転記しません。例はすべて**書式を模した合成値**です。

## DOM 構造

各エントリは 1 つの `<a class="result" name="{bib}">`。中に 2 ブロック:

- `.nwb` スパン ×3: `["{順位}位", "No.{bib}", "[{TEAM}]{氏名}"]`
- `.nw` スパン ×3: `["{フェーズ}", "{タイム}", "+Top : {ギャップ}"]`

順位は `.nwb[0]`（例 `12位`）。チームコードは氏名先頭の `[TUK]` 等。ギャップは `+Top : ` を除いた残り。

## レース種別と書式

| 種別 | フェーズ | タイム | ギャップ |
|---|---|---|---|
| **個人TT** | `中間点`（途中）/ `FINISH` | `0:02:57.94`（H:MM:SS.**cc** 1/100秒） | `+0:01.18` / `0:00.00` |
| **クリテリウム** | `10周`（完走＝周回数）/ `4周`（リタイア） | `0:33:47`（H:MM:SS 秒） | `+1:55`（時間差）/ `-4周`（周回遅れ） |
| **ロード** | `FINISH` / `3/6周`・`4/6周 SP2`（リタイア＝完了周回/総周回＋通過点） | `2:39:06`（H:MM:SS 秒） | `+2:54` / `-2周` |

## 種別の自動判定（`detectRaceShape`）

優先順位:

1. `ctg=004`（大鹿）**または**ページ・タイトル/見出しの「チームTT / Team Time Trial / TTT」語 → **team_tt**（`looksLikeTeamTT`。チームと個人はサブ秒タイムの内容だけでは区別しづらく、全日本TTTの ctg は英字で事前列挙できないため、ページ自身の表記で判定。サブ秒判定の前に評価する）。
2. 1/100秒タイム（`\d\.\d{2}`）または `中間点` フェーズ → **individual_tt**（TTは必ずサブ秒計測）。
3. `N周` / `X/Y周` フェーズ → **mass_start**。
4. 秒精度で同タイムが複数（集団ゴール）→ **mass_start**。
5. それ以外（空ページ等）→ **individual_tt**（安全側の既定。データ掲載後に再判定）。

## 重要な手がかり

- **完走 vs 周回遅れ（マススタート）**: ギャップが**時間**（`+M:SS`）なら先頭集団／完走、`-N周` なら周回遅れ。フェーズが `FINISH` か `N周` かに関わらず使える信頼シグナル。
- **着順**: マススタートは集団同タイムのため**タイムで順位を決められない**。公式の `位`（`.nwb[0]`）をそのまま採用する。
- **フェーズ文法**: `(\d+)/(\d+)周` = 完了周回/総周回。末尾 `SP\d`/`KOM` = 直近の通過計測点。`N周`（クリテリウム）= 完了周回数（総周回はページに無い）。
- **総周回**: ロードはリタイア行の `X/6周` から取得可能。クリテリウムは `/総` 表記が無く不明（先頭の最大周回数で代用）。
- **未掲載ステージ**: 結果が無いと「データがありません」の1行のみ。`parseEntries` は拾わない（空＝待機表示）。

## 全日本選手権 ロードレース（`evt=…_jprr`）

マススタート（ロード）として判定・表示する。フェーズは `N周`（完走者も `FINISH` ではなく最終周回数で出ることがある）、周回遅れは `-N周` ギャップ。**総周回数はページの `X/Y周` 表記から読み取り、固定値はハードコードしない**（会場・距離・周回数は年度毎に異なる）。

- 例（第94回）：**新潟県南魚沼市・三国川ダム周回コース／1周 12km**。男子エリート＝12km×15周＝180km、他カテゴリ（MM／Men U23／Women Elite+WU23／WM）は周回数が異なる。
- カテゴリ（`ctg`）例：`ME-R`(Men Elite) / `MM-30`・`MM-50`(Men Master) / `MU-R`(Men U23) / `WE-R`(Women Elite+WU23) / `WM`。実コードは年度毎に当日確認。
- SPA プレビュー `?mock=jprr` で上記カテゴリのタブ＋周回遅れ・集団状況を合成データで事前確認できる（表示確認専用）。

## 全日本選手権 個人TT・チームTT（会場は年度毎に当日確認）

**注**：会場・距離・周回数・中間点は**年度毎に変わる**。下表は **2026 年版（宮崎・1周 14.2km）の推定**で、最新値はレース当日に実ページで確認すること。`evt=…_jptt`（2025 は `250629_jptt`）。カテゴリは**数値ではなく英字コード**で、個人TTは接尾辞 `-T`：

| ctg | カテゴリ | 距離 | 周回（**1周 = 14.2km**） | 中間点（推定） |
|---|---|---|---|---|
| `ME-T` | 男子エリート 個人TT | 42.6km | **×3周** | 周回ごとの S/F 通過＝**中間点 ×2** → FINISH |
| `MU-T` | 男子U23 個人TT | 28.4km | **×2周** | 中間点 ×1 → FINISH |
| `WE-T` | 女子エリート+U23 個人TT | 14.2km | **×1周** | 中間点なし（1周）→ FINISH |
| （未確定の英字コード） | チームTT | 28.4km | **×2周** | LAP1（14.2km）→ FINISH |

出典：[2026 全日本TT実施要項](https://jcf.or.jp/events/2026nc-tt/?category=road)（コース 14.2km/周、ME=42.6km・MU23=28.4km・WE+WU23=14.2km・TTT=28.4km を明記）。周回・中間点は**周回コース（S/F を毎周通過）前提の推定**。

**実装上の要点**

- **チームTT判定**：大鹿は `ctg=004`、全日本TTT は ctg が英字で事前列挙不能なので**ページ・タイトル/見出しの「チームTT / Team Time Trial / TTT」語**で判定（`looksLikeTeamTT` → `detectMode`/`detectRaceShape`）。個人TT（「個人タイムトライアル」）はチーム語を含まず誤判定しない。自動判定が外れても**ヘッダーの 個人/チーム トグルで手動切替**可能。
- **チームTT周回数**：`teamLaps(href)` が `evt` に `jptt` を含めば **2周**、それ以外（大鹿）は **3周**。`parseTeam` の既定値・`enrichTeamsWithLaptimes` の取得周回数・チームタワーの「Lap N」列数すべてに反映。
- **当日の確認事項**：① TTT の実 ctg コード、② TTT ページのタイトル表記が team 語を含むか（含まなければ手動トグルで対応）、③ 中間計測の実フェーズ表記（`LAP1`/`1周`/`中間点` 等）。
